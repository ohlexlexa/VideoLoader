# Загрузка видео

Приложение для macOS, которое скачивает видео, звук и фото. К нему прилагается расширение
для Chrome и Яндекс Браузера: оно добавляет кнопку «Скачать» на сайтах и отправляет
ролик в приложение. Скачивает приложение через yt-dlp и ffmpeg, а там, где yt-dlp
не справляется, забирает файлы напрямую.

## Как это выглядит

**Приложение.** Ссылки приходят из браузера или вставляются в поле. Видно ход загрузки, готовый
файл можно открыть, показать в Finder или удалить.

<img src="docs/app.png" alt="Окно приложения: одна загрузка идёт, две готовы" width="700">

**YouTube.** Под видео появляется кнопка «Скачать»: основная часть качает с настройками приложения,
▾ открывает список качеств ролика и звук.

<img src="docs/youtube.jpg" alt="Кнопка «Скачать» под видео YouTube с открытым списком качеств" width="700">

**Главы.** Если у ролика на YouTube есть главы, они сохраняются прямо в файле: в видео и в звуке
m4a и mp3. В QuickTime список глав с превью открывается кнопкой » на панели управления → «Главы»,
по ним можно переходить. IINA и VLC главы тоже показывают.

<img src="docs/quicktime-chapters.jpg" alt="Скачанный ролик в QuickTime: открыт список глав с превью и временем" width="700">

**Окошко расширения** (по клику на значок). На уроке GetCourse — все видео страницы по порядку,
с превью, заголовком блока и качествами потока. Так же оно работает для Instagram, Threads и Vimeo.

<img src="docs/popup-getcourse.png" alt="Окошко расширения на уроке GetCourse: четыре видео с кнопками качества" width="380">

## Откуда качает

| Сайт | Что умеет |
|---|---|
| YouTube | Кнопка «Скачать ▾» под видео со списком качеств ролика, звук m4a и mp3, Shorts, до 4K; главы ролика встраиваются в файл (в QuickTime — » → «Главы») |
| GetCourse | Все плееры урока в порядке страницы, превью, заголовок блока в имени файла, выбор качества из HLS-потока |
| Instagram | Reels и видео в 1080p; карусели и фото — папкой `01.jpg, 02.mp4…`; посты, видимые в ленте, профиле и «Интересном» |
| Threads | Видео поста и остальные ролики со страницы, с превью и пометкой «без звука» |
| Vimeo | Обычные и скрытые ссылки (`vimeo.com/ID/ключ`), выбор качества |

Любую другую ссылку, которую понимает yt-dlp, можно вставить в поле приложения.

Все видео открываются в QuickTime. Приложение берёт лучшее качество, а если оно есть только
в VP9 или AV1 (4K на YouTube, Instagram), после загрузки перекодирует его в H.264 встроенным
кодировщиком Mac, с сохранением глав. Галочка «Без перекодирования» сразу берёт H.264: готово
быстрее, но качество обычно не выше 1080p.

## Установка

### Готовое приложение

1. Скачать `VideoLoader-macOS.zip` из последнего релиза:
   [Releases](https://github.com/ohlexlexa/VideoLoader/releases/latest).
2. Распаковать архив и перетащить «Загрузка видео.app» в «Программы».
3. Запустить приложение. В первый раз macOS его заблокирует: оно подписано без сертификата
   разработчика. Открыть «Системные настройки → Конфиденциальность и безопасность» и нажать
   «Всё равно открыть». Или выполнить в Терминале:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Загрузка видео.app"
   ```
4. Если не хватает yt-dlp, ffmpeg или deno, само откроется окно «Компоненты»: там всё
   ставится одной кнопкой через Homebrew. Если Homebrew нет, установка пойдёт в Терминале,
   и там понадобится пароль администратора.
5. В том же окне нажать «Установить» у Chrome или Яндекс Браузера, затем включить
   «Режим разработчика» на странице расширений и перетащить на неё папку `chrome-extension`,
   открытую в Finder.

### Сборка из исходников

Нужны Xcode Command Line Tools (`xcode-select --install`).

1. Скачать проект и собрать приложение. Скрипт сам поставит его в «Программы»:
   ```bash
   git clone https://github.com/ohlexlexa/VideoLoader.git
   cd VideoLoader
   ./build.sh
   ```
2. Запустить «Загрузка видео». Предупреждения macOS при этом не будет: приложение собрано
   на этом Mac.
3. Поставить компоненты и расширение, как в шагах 4–5 выше.

Чтобы перенести приложение на другой Mac, достаточно скопировать `Загрузка видео.app`:
расширение уже внутри, а компоненты ставятся из окна «Компоненты».

## Как устроено

```
расширение (страница сайта)  ──videoloader://…──►  приложение  ──►  yt-dlp / ffmpeg / прямые загрузки
```

- **Приложение** (`main.swift`, SwiftUI + AppKit). Принимает ссылки `videoloader://`,
  запускает yt-dlp, показывает прогресс в окне и на значке в Доке.
- **Ссылки от расширения:**
  - `videoloader://download?url=…&mode=video|m4a|mp3&quality=<высота>&title=<имя файла>`
  - `videoloader://gallery?title=…&items=[{"u":"<прямая ссылка>","k":"jpg|mp4"}]` — набор файлов (карусель).
- **Расширение** (`chrome-extension/`, Manifest V3):
  - `content.js` + `page-bridge.js` — кнопка на YouTube и список качеств из плеера;
  - `instagram-bridge.js` — запоминает посты Instagram из фоновых запросов ленты;
  - `background.js` — ловит HLS-потоки GetCourse, пункты контекстного меню;
  - `popup.*` — окошко по клику на значок: GetCourse, Instagram, Threads, Vimeo, YouTube.
- **Временные файлы** лежат в `~/Library/Caches/VideoLoader`, в «Загрузки» попадает только
  готовый файл. Недокачанное удаляется при отмене, ошибке, выходе и запуске.
- **Журнал входящих ссылок:** `~/Library/Logs/VideoLoader.log`.

## Файлы

| Файл | Что это |
|---|---|
| `main.swift` | Всё приложение |
| `build.sh` | Сборка универсального бинарника, иконки, Info.plist, подпись, установка в «Программы» |
| `make_icon.swift` | Рисует иконку 1024×1024 |
| `set_icon.swift` | Ставит «свою» иконку приложению, чтобы macOS не затемняла её в тёмном режиме |
| `chrome-extension/` | Расширение для Chrome и Яндекс Браузера |

## Требования

macOS 14+, Apple Silicon или Intel. Для сборки — Xcode Command Line Tools (`swiftc`).

Скачивайте только то, на что у вас есть права: свои курсы, материалы с разрешённым
сохранением, видео для личного просмотра.
